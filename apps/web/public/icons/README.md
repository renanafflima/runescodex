# Ícones do PWA

Os arquivos SVG deste diretório são placeholders técnicos, não são a marca
definitiva do RuneCodex.

Antes da publicação, substitua-os por ícones oficiais exportados, no mínimo,
nos formatos 192x192, 512x512 e 512x512 maskable. Ao trocar para PNG, atualize
também as entradas `icons` em `vite.config.ts`.
